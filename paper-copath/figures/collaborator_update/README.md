# Co-pathology collaborator update figures

All figures use REGION-RF estimates after iterative low-likelihood chain removal.
Unless explicitly named `all_412_regions`, analyses use pathology-active regions and retain one-chain fits.

01. `region_rf_convergence_iterative_chain_filter`: convergence summary after iterative chain filtering.
02. `parameter_ttests_pathology_active_mapt_zscore`: APP vs MAPT parameter shifts for pathology-active regions, MAPT-referenced z scale.
03. `parameter_ttests_all_412_regions_mapt_zscore`: same parameter-shift panel including all atlas regions.
04. `gamma_high_low_pathology_active`: MAPT gamma low/high stratification and APP-associated gamma shifts for pathology-active regions.
05. `gamma_high_low_all_412_regions`: same gamma stratification panel including all atlas regions.
06. `ab40_amyloid_vs_parameter_shifts`: AB40 load vs APP-MAPT shifts in r, beta, gamma.
07. `ab42_amyloid_vs_parameter_shifts`: AB42 load vs APP-MAPT shifts in r, beta, gamma.
08. `celltype_vs_parameter_shifts`: cell-type composition correlations with APP-MAPT parameter shifts.
09. `transcriptomic_pathways_parameter_shifts`: direct parameter-level pathway GSEA, no PCA.
